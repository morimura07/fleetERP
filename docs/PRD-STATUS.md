## Foundation gaps (contractual, PRD §6–§7)

These are **Phase-1 "non-negotiable" requirements** not yet met. Cheaper to fix before more modules stack on top:

1. **`Row_Version` optimistic concurrency** (§7.1) — absent on all models. Hard architectural requirement.
2. **Audit metadata** (§7.1) — `Last_Modified_By` / full GUID metadata not on every table; ~12 of 31 models have `createdById`.
3. **Enforced `dataAreaId` partitioning** (§6.2) — column exists on accounting tables but is **not enforced at the query layer** (a KE01 finance user can read HQ01 data), and ~11 operational models have no `dataAreaId` at all.
4. **Multi-currency revaluation** (M8) — rates stored, but no period-end revaluation run.
